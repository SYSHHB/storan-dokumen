# SYSHHB IT Documents

The package contains the portal-themed document library page and its companion configuration, service worker, manifest, and icons.

## Publish with GitHub Pages

1. Upload the files in this folder to the root of the repository.
2. In **Settings → Pages**, publish from your chosen branch and `/ (root)`.
3. Open the HTTPS Pages address. Install through the browser menu or the app install prompt when available.

The PWA requires HTTPS. Review `config.js` before using a public repository because it contains deployment-specific account and storage settings.
